# Look to Lucky

App para Windows que abre vários canais da Kick lado a lado e transforma o seu tempo de audiência em créditos, para apoiar quem transmite.

**[⭳ Baixar a última versão](https://github.com/guilhermedamasio/LookToLucky-releases/releases/latest/download/LookToLucky.zip)** · [looktolucky.com.br](https://looktolucky.com.br)

## Como instalar

1. Baixe o `LookToLucky.zip` e extraia em qualquer pasta.
2. Rode o `LookToLucky.exe`. Não tem instalador.
3. Crie a conta e informe o seu código de convite.
4. Autorize o app na tela oficial da Kick. É uma vez só.

## Requisitos

- Windows 10 ou 11 (64 bits)
- WebView2 (já vem no Windows)
- Conta na Kick
- Código de convite — o app está em beta fechado
